Privacy Policy

Effective November 18, 2026

Clipforge Uploader ("the app") is a desktop tool for editing short gaming clips and sending them to a connected TikTok account as drafts.

What the app accesses

  • With the user.info.basic permission: the connected TikTok account's open ID, display name and avatar. The app uses these to confirm that the right account is connected.
  • With the video.upload permission: the app sends clips the user has edited to that account's TikTok inbox as drafts.

What it stores

The app keeps the TikTok access token on the user's own computer, in a file only that user can read. It does not run a server and keeps no database of users.

Sharing

The app does not sell, rent or share any data. It sends data only to TikTok, to upload drafts. It uses no analytics, advertising or tracking.

Removing access

You can revoke the app's access at any time in the TikTok app: Settings and privacy → Security → Manage app permissions. Users can also delete the stored token from their computer at any time.

Children

The app is not directed at children and collects no data from them.

Changes and contact

This policy may be updated. The effective date above shows the latest version. For questions, open an issue.
