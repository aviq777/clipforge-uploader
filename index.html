Clipforge Uploader

Clipforge Uploader is a private desktop tool. Its owner uses it to edit short gaming clips and send them to the owner's own TikTok account as drafts. The owner then reviews, edits and posts each draft in the TikTok app.

It is not a public service. Nobody else can sign up for it or use it.

It uses TikTok Login Kit to connect the owner's account and the Content Posting API, only to upload drafts to that account's inbox. It does not post directly, and it never acts on anyone else's account.
